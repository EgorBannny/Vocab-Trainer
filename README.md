# 📚 Vocab Trainer — учим английские слова

Статический сайт (чистый HTML + CSS + JavaScript, **без сборки и без серверной части**) для изучения английских слов:

- **Карточки**: на одной стороне слово по-русски и его определение, на другой — английское слово, транскрипция, 🔊 произношение, часть речи и пример.
- **Связанные значения**: если у слова несколько значений (например `mouse` — «мышь» компьютерная и «мышь» животное, `key` — «клавиша» и «ключ», `bug` — «баг» и «жук»), карточки связываются автоматически и на обороте показывается блок «Другие значения».
- **Словарные диктанты**: рус → англ, англ → рус или вперемешку. Можно выбрать несколько наборов и указать, сколько слов взять из каждого. Ошибки не прощаются, но регистр букв и «е/ё» не важны.
- **Слабые места**: все ошибки запоминаются в браузере. Слово считается слабым, пока ты не ответишь на него правильно 3 раза подряд. Слабые слова можно повторить карточками или диктантом.
- **Разделы и подразделы**: IT, Жизнь, Другое. У каждого набора есть уровень сложности (Лёгкий A1 / Средний A2 / Сложный B1).
- **10 стартовых наборов** (около 160 слов): 5 по IT, 4 из раздела «Жизнь», 1 из раздела «Другое».
- Экспорт и импорт прогресса в файл, тёмная тема (автоматически), адаптивная вёрстка для телефона.

## Файлы проекта

```
index.html   — страница
style.css    — стили
app.js       — вся логика (карточки, диктанты, слабые места)
data.js      — наборы слов (сюда добавляешь свои)
README.md    — этот файл
```

Все пути в проекте относительные, поэтому сайт одинаково работает и по адресу `https://имя.github.io/репозиторий/`, и локально.

## Деплой на GitHub Pages — пошаговая инструкция

### Что нужно заранее

1. Аккаунт на [github.com](https://github.com) (регистрация бесплатная).
2. Репозиторий должен быть **публичным** (Public). На бесплатном тарифе GitHub Pages для приватных репозиториев недоступен.

### Вариант A. Через веб-интерфейс GitHub (проще всего, без установки git)

1. Войди на GitHub и нажми **«+» → New repository** (вверху справа).
2. В поле **Repository name** введи название, например `vocab-trainer`.
3. Выбери **Public**.
4. Галочку «Add a README file» **не ставь** (файл уже есть в проекте). Нажми **Create repository**.
5. На странице нового репозитория нажми ссылку **uploading an existing file**.
6. Перетащи в окно **файлы** проекта: `index.html`, `style.css`, `app.js`, `data.js`, `README.md`. Загружай именно файлы, а не папку, в которой они лежат. Иначе `index.html` окажется внутри подпапки и сайт не откроется.
7. Внизу страницы нажми **Commit changes**.
8. Включи Pages (см. раздел ниже).

### Вариант B. Через git в терминале

1. Установи git: [git-scm.com/downloads](https://git-scm.com/downloads). Проверь: `git --version`.
2. Один раз представься git (подставь свои данные):
   ```bash
   git config --global user.name "Твоё Имя"
   git config --global user.email "ты@example.com"
   ```
3. На GitHub создай пустой публичный репозиторий (шаги 1–4 из варианта A). Запомни его адрес, например `https://github.com/ИМЯ/vocab-trainer.git`.
4. Открой терминал в папке с файлами проекта и выполни:
   ```bash
   git init
   git add .
   git commit -m "Первая версия сайта"
   git branch -M main
   git remote add origin https://github.com/ИМЯ/vocab-trainer.git
   git push -u origin main
   ```
5. При `git push` GitHub попросит авторизацию. Пароль от аккаунта больше не принимается, нужен один из способов:
   - **GitHub CLI**: поставь [cli.github.com](https://cli.github.com), выполни `gh auth login` и следуй подсказкам. Затем повтори `git push`.
   - **Personal Access Token**: на GitHub открой *Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token*, поставь галочку `repo`, скопируй токен и вставь его вместо пароля.
   - **SSH-ключ**: если он у тебя настроен, используй адрес вида `git@github.com:ИМЯ/vocab-trainer.git`.

### Включение GitHub Pages (для обоих вариантов)

1. Открой свой репозиторий на GitHub и перейди на вкладку **Settings**.
2. В левом меню выбери **Pages**.
3. В блоке **Build and deployment → Source** выбери **Deploy from a branch**.
4. В блоке **Branch** выбери ветку **main** и папку **/ (root)**, затем нажми **Save**.
5. Подожди 1–3 минуты. Прогресс виден на вкладке **Actions** (workflow «pages build and deployment»). Когда рядом появится зелёная галочка, сайт готов.
6. Обнови страницу **Settings → Pages**. Вверху появится сообщение *Your site is live at …* со ссылкой.

Адрес сайта будет таким:

- обычный репозиторий: `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`
- если назвать репозиторий **`ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io`**, сайт будет доступен по короткому адресу `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/`

### Как обновлять сайт

- **Через веб-интерфейс**: открой файл в репозитории, нажми ✏️ (Edit), внеси изменения и нажми **Commit changes**. Либо **Add file → Upload files** и загрузи новую версию, она заменит старую.
- **Через git**:
  ```bash
  git add .
  git commit -m "Добавил новые слова"
  git push
  ```

После каждого пуша Pages пересобирается за 1–2 минуты. Если изменений не видно, обнови страницу с очисткой кэша (**Ctrl+F5**, на Mac **Cmd+Shift+R**).

### Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Ошибка **404** по адресу сайта | Подожди 2–3 минуты после включения Pages. Проверь, что в *Settings → Pages* выбраны ветка `main` и папка `/ (root)`. |
| Страница пустая или без оформления | Проверь, что `index.html`, `style.css`, `app.js`, `data.js` лежат **в корне** репозитория, а не в подпапке. Имена файлов должны совпадать **с учётом регистра**: на GitHub Pages `App.js` и `app.js` — разные файлы. |
| Pages недоступны в Settings | Репозиторий должен быть публичным (или нужен платный тариф). |
| Нет звука при нажатии 🔊 | Озвучка использует голоса твоего браузера и ОС (Web Speech API). Лучше всего работает в Chrome, Edge и Safari. Если голосов нет, установи английский голос в настройках системы. |
| После правок данных ничего не изменилось | Очисти кэш (Ctrl+F5). Открой консоль браузера (F12): ошибки в `data.js` (например, потерянная запятая) там будут видны, и тогда сайт покажет пустую страницу. |
| Пропал прогресс | Он хранится в `localStorage` браузера. Он сбрасывается, если очистить данные сайта, использовать другой браузер или устройство, либо сменить адрес сайта. Регулярно жми «Сохранить прогресс в файл» на вкладке «Слабые места». |

## Как добавить свои слова

Все наборы лежат в `data.js`. Каждая карточка — одна строка:

```js
c('мышь', 'компьютерная', 'Небольшое устройство, которым двигают курсор на экране.',
  'mouse', '/maʊs/', 'сущ.', 'Click the icon with the mouse.')
```

Порядок аргументов: `c(русский, пометка, определение, английский, транскрипция, часть_речи, пример)`.

- **Несколько вариантов перевода** пишутся через `|`: `'батарея|аккумулятор'`, `'mother|mom'`. В диктанте принимается любой из них. Показывается первый.
- **Транскрипция**: если вариантов английского несколько, укажи транскрипции в том же порядке через `|` (если указана одна, она используется для всех).
- **Пометка** (второй аргумент) нужна, чтобы различать значения («компьютерная» / «животное»). Если она не нужна, оставь `''`.
- **Связи между значениями создаются сами**: если у двух карточек одинаковое английское слово (`mouse`, `key`, `window`, `table`, `cloud`, `bug`) или одинаковый русский перевод, они показываются друг у друга в блоке «Другие значения». В диктанте «англ → рус» для такого слова принимаются все его русские переводы.

Новый набор добавляется в конец списка `window.VOCAB_SETS`:

```js
{
  id: 'life-travel',          // уникальный id латиницей, потом не меняй
  cat: 'Жизнь',               // раздел (можно придумать новый, например 'Работа')
  sub: 'Путешествия',         // подраздел
  level: 1,                   // 1 = Лёгкий (A1), 2 = Средний (A2), 3 = Сложный (B1)
  title: 'В аэропорту',
  desc: 'Слова для путешествия на самолёте.',
  cards: [
    c('паспорт', '', 'Документ, который нужен для поездки за границу.', 'passport', '/ˈpæspɔːrt/', 'сущ.', 'Do not forget your passport.'),
    // ...
  ]
},
```

**Важно:** статистика ошибок привязана к паре «id набора + английское слово + русское слово». Если переименуешь их у существующей карточки, её история сбросится. Новые слова можно добавлять свободно.

## Как это работает

- Прогресс (ошибки, серии правильных ответов, настройки) хранится в `localStorage` браузера под ключом `vocab-trainer.v1`. Никакие данные никуда не отправляются.
- Произношение использует встроенный в браузер синтез речи (`speechSynthesis`, язык `en-US`), поэтому интернет и API-ключи не нужны.
- Слабое слово: хотя бы одна ошибка и меньше 3 правильных ответов подряд.
